        智能增强
        
    
        自动召回经验知识
        发问前自动检索知识库并注入相关片段（按需，KB 为空则跳过）        
      
        
    
        任务完成自动沉淀经验
        把每次真实任务的摘要写入知识库，供将来召回        
      
        
    
        自主维护记忆
        开启：模型提议的工作规则/知识/经验直接写入对应文件（可一键撤销、有审计）；关闭：先进草稿，等你审批        
      
        
    
        工作区规则自动沉淀
        开启：模型提议的工作区规则直接写入 RULES.md（可一键撤销、有审计）；关闭：先进草稿，等你手动审核        
      
        
    
        默认沉淀到「本工作区」；在记忆面板「自主沉淀」里可把通用条目「升级为全局」，使其对所有工作区生效，也可把全局条目「降级」回当前工作区。
        
    
        记忆文件语义压缩
        超过软阈值时，用模型把知识库/经验库合并得更紧凑（仅知识/经验）；工作规则只做无损去重、绝不改写语义        
      
        
    
        长对话自动压缩
        上下文接近上限时自动摘要压缩，避免质量退化        
      
        
    
        
      
      
        左端=自动（按窗口算最佳值），右滑=手动钉一个百分比
        
    
        压缩时可恢复归档
        被折叠的旧历史写入工作区 .Nebula-archive/ 便于随时读回；最近决策/任务状态始终驻留        
      
        
    
        冷归档文件管理
      
        
    
        
    
        
    
        
      
      
        左端=压得更狠，右端=保留更多近期原文
        
    
        
      
      
        连续分段压缩仍装不下时，最多重试几次后停止并告警（防压缩死循环）。默认 2
        
    
        
      
      
        每次压缩后 sparkline 保留压缩前最近多少根柱（虚线分隔当前段）。默认 10，设 0 = 不保留
        
    
        
      
      
        sparkline 总共最多显示多少根柱（冻结段+当前段）。达上限后最左柱平滑滚出；默认 24
        
      
        
        
        
        仅在阈值滑条=自动时生效：解码速度较安静期基线下降达此百分比即提前压缩；左端灵敏，右滑迟钝
        
      
        
      
        
        
        Tokens per semantic-merge chunk; 0 = auto. Larger = fewer chunks, closer to window overflow.
        
      
        
      
        
      
        
        
        Window share reserved for the merge reply (auto mode). Inert on large windows; disabled when the chunk budget is pinned. Default 25%.
        
      
        
    
        自主推进
        
    
        AI 自动续跑建议
        AI 回答后自动选择其给出的建议/下一步继续推进，无需手动点击（默认只跑它标注的推荐项）        
      
        
    
        仅推荐项（默认只跑绿色）
        开：仅推荐项关：推荐+普通项
        
    
        隐藏不推荐建议
        开：建议条里不显示不推荐（红）档；关：如常显示
        
    
        下一步建议颜色即决定
        
    
        压缩后自动续跑
        开启：压缩输出摘要后自动续跑被打断的未完成任务（3 秒内可撤销）；关闭：压缩后本轮自然收尾，等你点「继续」再续        
      
        
    
        中断后自动续跑
        思考/工具途中被切断（掉线、看门狗、轮次上限）时自动接着做，无需手动点「继续」；连续 3 次仍中断则交回给你        
      
        
    
        
      
      
    
        
    
        
      
      
    
        
    
        
      
      
    
        
    
        自动修复收集箱 bug
        开启后 AI 空闲时自动取最旧一条未修复的 bug 发起修复任务（推送即标 fixing 防自反馈）；修复需复现+门禁双绿才标 verified 并移出收集箱，审计留 JSONL。        
      
        
    
        Auto-verify green-tested fixes
        When on: a fix whose regression test came back green this turn is auto-marked verified and removed from the box.        
      
        
    
        强制中文思考
        让模型用中文推理（可能更慢、token 更多，可用统计条实测）        
      
        
    
        执行过程折叠
        带工具调用的回合，把中间叙述/思考/工具收纳为可展开的「执行过程」，只完整展示最终回答        
      
        
    
        调试页卡片默认折叠
        调试页各卡片默认折叠，仅显示标题        
      
        
    
        记忆页卡片默认折叠
